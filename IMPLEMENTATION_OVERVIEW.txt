┌─────────────────────────────────────────────────────────────────────────────┐
│                        USER JOURNEYS                                        │
└─────────────────────────────────────────────────────────────────────────────┘

JOURNEY 1: New User Signup
  1. Visit http://localhost:3000 (home page)
  2. Click "Analyze Code" button
  3. Redirected to /signup (CTA check → not logged in)
  4. Fill in: Full Name, Email, Password
  5. Click "Create Account"
  6. Client validation checks fields
  7. API call: supabase.auth.signUp()
  8. Supabase creates user account
  9. Session token created
  10. Stored in secure cookie
  11. Redirected to /analyzer
  12. useAuth hook sees session
  13. Analyzer page renders
  14. User can analyze code
  Time: ~5 seconds

JOURNEY 2: Returning User Login
  1. Visit http://localhost:3000
  2. Click "Log In" button
  3. Redirected to /login
  4. Enter: Email, Password
  5. Click "Sign In"
  6. Client validation checks fields
  7. API call: supabase.auth.signInWithPassword()
  8. Supabase verifies credentials
  9. Session token created
  10. Stored in secure cookie
  11. Redirected to /analyzer
  12. useAuth hook sees session
  13. Analyzer page renders
  14. User can analyze code
  Time: ~3 seconds

JOURNEY 3: Direct Access (Logged Out)
  1. Type: http://localhost:3000/analyzer
  2. Browser loads page
  3. Middleware runs (server-side)
  4. Checks session in cookies
  5. No session found
  6. Middleware redirects to /login
  7. User sees login page
  8. Must login first
  Time: <1 second

JOURNEY 4: Logout
  1. In analyzer page
  2. Click "Sign Out" button
  3. onClick handler calls logout()
  4. useAuth calls: supabase.auth.signOut()
  5. Supabase clears session
  6. Cookie deleted
  7. Router redirects to /
  8. User back on home page
  9. No longer authenticated
  Time: ~1 second
